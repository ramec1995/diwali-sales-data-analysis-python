# Diwali Sales Data Analysis | Python

## Project Overview

Performed exploratory data analysis on Diwali sales data using Python to identify customer purchasing behavior and sales trends.

## Libraries Used

* Pandas
* NumPy
* Matplotlib
* Seaborn

## Data Cleaning

* Removed null values
* Dropped unnecessary columns
* Converted datatypes
* Renamed columns

## Analysis Performed

* Gender-wise sales analysis
* Age group analysis
* State-wise sales trends
* Occupation analysis
* Product category analysis
* Zone-wise sales analysis

## Business Insights

Married women aged 26–35 working in IT, Healthcare, and Aviation sectors were identified as the highest purchasing customer segment.
